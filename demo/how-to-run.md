# How to Run the Demo

This demo is fully reproducible using the provided simulator.

No external hardware or cloud services are required.

---

## Prerequisites

- Node.js or Bun runtime
- Git

---

## Steps

```bash
# Clone the repository
git clone https://github.com/umangPokhriyall/auto-resurrect-runtime.git
cd auto-resurrect-runtime

# Install dependencies
bun install

# Run the simulator
cd apps/simulator
bun index.ts
